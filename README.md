# 从像素到预测：CNN 手写数字入门课

在自己的 Windows 电脑上打开中文课程网页，跟着页面观察图片、卷积和训练，再用鼠标写一个数字试试识别。**不需要先学编程、导数或命令行**；安装和首次下载仍需要 Python 与网络。

## 第一次使用

1. 按 [Windows 零基础启动指南](docs/windows-start.md) 安装 Python（3.11 或更新版本），在项目文件夹里双击 `install.bat` 安装依赖。首次安装需要联网，可能花些时间。
2. 双击 `start.bat`，等待浏览器打开 <http://127.0.0.1:5000>。如果没有自动打开，把地址复制到浏览器地址栏；启动窗口要保持打开。**没有 MNIST 数据也能先打开课程**。
3. 从「从像素开始」进入章节目录，按 **00 开始使用 → 01 数字图片 → 02 找局部线索 → 03 组合成网络 → 04 让机器学习 → 05 检查是否真会 → 06 自己试一试** 学习。到训练课准备运行真实训练时，按指南下载 MNIST 数据；首次下载需要联网。网页不会自动训练，CPU 就能使用，无须显卡。

遇到「找不到 Python」「缺少依赖」「数据尚未准备」或网页打不开，请到 [Windows 零基础启动指南](docs/windows-start.md) 按提示排查。依赖默认放在项目的 `libs/` 文件夹，后来下载的数据生成到 `data/mnist.npz`；不必在课程开始前阅读代码。

## 学习路线

- [学习指南](docs/learning-guide.md)：按网页顺序学习，从像素到自己的第一次训练；不用写代码。
- [实验记录](docs/experiments.md)：只改网页里的一个旋钮，记录观察；基础实验不用改代码。
- [数学进阶（选修）](docs/advanced/math.md)：从四则运算理解卷积和权重更新，导数放在最后。
- [Python 与源码（选修）](docs/advanced/python-and-source.md)：准备好读代码后再运行 `examples/` 中的四个脚本，了解它们与网页的关系。

原 `examples/` 脚本是选修练习，不是使用网页的前提。想尝试 NVIDIA GPU 可在完成 CPU 路线后查看项目中的 `install_cuda.bat`；不用 GPU 也能学完。
