# 学习指南：沿网页 00–06 章节学习

第一次学习只需要打开网页、阅读文字、点击按钮和记录观察。**不要求会写 Python、看懂源码或计算导数**；`examples/` 四个脚本是选修，不是课程入口。先按 [Windows 零基础启动指南](windows-start.md) 安装 Python 和本项目 `libs/` 依赖，双击 `start.bat` 打开 <http://127.0.0.1:5000>。**打开课程不需要先下载 MNIST**；到真实训练前再下载数据。首次装依赖及首次下载数据分别需要联网。

## 从哪里开始

在开始页找到「从像素开始」，进入章节目录。从 **00 开始使用** 起按顺序阅读；每课都可以先猜、动手、看反馈，再用自己的话解释，也可以返回或跳到别的章节。以下是网页主线，不是另一份必须完成的脚本课表。

| 章节 | 在网页上做什么 | 可以试着回答 |
|---|---|---|
| **00 开始使用** | 认清项目文件夹、安装步骤和本机网页地址，查看环境与数据状态。 | 浏览器页面和项目文件夹是一回事吗？没有 MNIST 时是否还能继续前面的课？ |
| **01 数字图片** | 点击像素方格，把小图案读成数字表，再看 28×28 图片。 | 电脑收到的是什么数，而不是“直接看见一个 7”？ |

| **03 组合成网络** | 沿图示把局部线索、汇集线索和最终分类连起来。 | 模型最后给出的十个数，为什么不是“保证正确”的答案？ |
| **04 让机器学习** | 在不需要 MNIST 的权重小练习里，猜哪种调整会使误差变小；想看真实训练时，再按下文下载数据、进入训练页。 | “预测 → 算误差 → 调整”为什么要在许多图片上反复做？ |
| **05 检查是否真会** | 用少量例子理解准确率，对照训练图片与未参与训练的图片，查看验证错例和指标。没有 MNIST 时仍可学习教学示意；真实验证结果要等训练完成。 | 为什么只看训练过的图片不能判断是否真正学会？ |

**到 04 的真实训练入口才需 MNIST。** 若提示数据尚未准备，保持网页启动窗口打开，按 [Windows 指引第 5 步](windows-start.md#5-到训练课再下载手写数字数据) 在项目文件夹的**另一**个 PowerShell 窗口运行 `python download_data.py`。下载完成后刷新课程页面，进入训练页点击「开始训练」；网页不会自动开始训练。CPU 速度因电脑而异，等一轮完成后再看验证样例和曲线。若仍提示缺数据，检查两个窗口指向同一项目文件夹。结束学习时关掉 `start.bat` 的窗口即可停止服务。

## 不用公式也能读懂结果

- **像素**：一张 28×28 灰度图有 784 个位置。每个位置的数值表示明暗；模型接收转换到 0–1 范围的数值。课程可先用小方格理解，再看真实图片。
- **卷积与池化**：小模板在图上移动，逐项相乘后求和，产生局部响应；池化保留小区域的较大响应。教学小矩阵不是正在训练的图片。
- **训练**：网络做预测、衡量与正确答案的差距（loss），再调整参数。一个 **batch** 是一小组图片，一个 **epoch** 是看完本次训练集一遍；不用先会推导梯度。
- **三份数据**：训练集用于更新参数；验证集用于观察并比较设置；测试集留作最终检查。网页会在每次**完整训练结束**显示一次测试结果，但不要根据反复看到的测试成绩挑参数，只用验证结果做实验比较。
- **loss 与准确率**：loss 较低通常表示这批预测更符合答案；准确率是预测对的比例，二者不相同。一次曲线上下波动、一次识别失败或小幅准确率差异，都不足以证明方法有效或无效。
- **预测分数**：模型先产生十个原始分数（logits），展示时才转换成总和为 1 的概率。最高概率并不等于保证猜对；混淆矩阵中行是真实数字、列是预测数字，非对角线表示错认。

## 想继续时再选分支
