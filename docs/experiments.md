# CNN 入门实验记录

先读 [学习指南](learning-guide.md) 并运行四个示例。本页是一张可复制的实验单：**每次只改变一个因素**，记录实际观察，不要把小样本一次运行的准确率当作结论。

## 起点：固定基线

先运行 `python download_data.py` 准备数据，再在项目根目录执行：

```bash
python examples/04_minimal_training.py --epochs 1 --max-samples 512 --device cpu
```

脚本固定随机种子 42，先从原训练集按类别划分训练/验证，再分别取最多 512 张；测试集不参与。记下每轮的训练/验证 loss 与准确率。不同机器速度可能不同，**不预设准确率必须达到某个数**。

## 实验 A：只增加训练轮数

```bash
python examples/04_minimal_training.py --epochs 3 --max-samples 512 --device cpu
```

与基线保持样本数量、设备一致，仅把轮数改为 3。记录**每一轮**的训练/验证指标：训练 loss 是否降低？验证 loss 是否同步降低？如果训练集继续进步、验证集反而变差，可能出现过拟合；单次波动不足以证明已经过拟合。

## 实验 B：只增加样本数量

```bash
python examples/04_minimal_training.py --epochs 1 --max-samples 2048 --device cpu
```

与基线保持轮数、设备一致，仅增大上限。注意 `--max-samples` **同时**改变训练集和验证集使用的数量：结果既受训练数据量影响，也受验证样本数变化影响，不能把差异完全归因于“训练数据更多”。如要做严格的单变量比较，需要固定验证集，修改实验代码或使用完整验证集另行评估。不要用未见过的测试集反复挑参数。

## 读数时别忽略这些

- **训练 loss** 衡量当前模型在所用训练图片上的交叉熵；**验证 loss** 衡量未参与更新的图片，两个数越小通常越好，但不是准确率的同义词。
- **训练准确率** 是训练过程中各 batch 预测的累计值：模型在一轮内不断变化且处于训练模式；验证准确率来自轮末固定模型的评估模式，不能直接当成同一时刻的严格对照。
- 小样本、数据顺序、设备数值计算都可能带来差异；即使固定种子，也不要把每一位小数视为跨机器的保证。
- 只有在确定了训练策略后，才能用从未参与调参的测试集做一次最终评估。本例刻意不计算测试成绩，也不保存模型权重。

写下结论时用“在本次设置下观察到……”而不是“CNN 一定……”。想观察更多设置（学习率、batch、Dropout），先读 `train.py` 与 `model.py`；这个最小示例的命令行目前只开放轮数、样本上限、设备和数据路径。
