# 数学进阶：从四则运算到可选导数

**选修，不是 [网页课程](../learning-guide.md) 的前提。** 先用加、减、乘、除理解数字图像、卷积与一次参数更新；看到最后仍不想学导数，可以停在倒数第二节。下面的小数字是为了手算，不是实际 MNIST 模型的一次训练结果。

## 1. 图片为什么可以计算

一张灰度图片是一张数字表：MNIST 图片宽 28 格、高 28 格，共 `28 × 28 = 784` 格。每个原始像素是 0–255：0 是黑，255 是白。除以 255 就把它换成 0–1；例如 `128 ÷ 255 ≈ 0.502`。这只是换单位，不是让模型突然“认出”数字。项目的 `examples/01_pixels_and_tensors.py` 展示这个转换（脚本可选，不用运行也可继续）。

## 2. 一个格子怎么算出来：先乘后加

设图片的一小块和扫描窗口（卷积核）分别是：

```text
图片小块       卷积核
1  2           1   0
3  4           0  -1
```

把同位置的数相乘，再全部相加：`1×1 + 2×0 + 3×0 + 4×(-1) = -3`。窗口移到下一个位置，**仍用同一组核数字**重复这件事；每个位置的结果排列起来就是特征图。负数输出也可能出现，不代表计算错误。实际模型的卷积核是从数据里学出来的，不一定是这里的整数；PyTorch 的 `Conv2d` 与网页 **02 找局部线索** 的模板滑动都按不翻转核的方式计算，严格说属于互相关。

然后 **ReLU** 把负数改为 0，正数保持原值：`[-2, 0, 3] → [0, 0, 3]`。**最大池化**从局部小块取最大值：`[1, 3; 2, 0] → 3`。卷积可以在同样位置产生不同的局部响应，池化可以缩小图片表示；它们不是“直接看懂”整个数字。网页中的 3×3 核和这里的 2×2 手算例子大小不同，但乘加规则相同。

## 3. 权重怎样影响结果

先想一个只有两个输入的玩具神经元：输入 `[2, 3]`，权重 `[0.5, -0.25]`，偏置 `0.1`，加权和为 `2×0.5 + 3×(-0.25) + 0.1 = 0.35`。经过 ReLU 还是 `0.35`。权重像旋钮：旋转它会改变输出；真实 CNN 有很多这样的可学习数字。

再看更简单的**单权重**例子：没有偏置、没有 ReLU，输入 `x=3`，权重 `w=2`，目标 `4`。预测 `w×x=6`，平方误差 `(6-4)²=4`。如果把权重改为 `1.88`，新预测 `1.88×3=5.64`，新平方误差 `(5.64-4)²=2.6896`，这一次确实更小。两套例子是分别演示“神经元输出”和“权重更新”，不要把单权重的误差公式套到前面的 ReLU 神经元上。

在真实的手写数字分类中，模型给 **0–9 各一个原始分数（logits）**；训练使用交叉熵损失，而不是上面的单数值平方误差。展示给人看的概率由这些分数转换得到，训练的 `CrossEntropyLoss` 不需要你先做 Softmax。一次预测错了也不等于下一次更新必定立刻改对。

## 4. 不用导数也能理解“往哪里调”

想象把权重向左或向右轻轻拨一下，再比较误差。误差变大的方向通常不是我们想要的；每次按估计的方向走一小步，反复处理不同图片。**学习率**控制步幅：太大可能跨过较好的位置，太小可能进展缓慢。训练过程中的 loss 可能上下波动，不能保证每一步都下降。到这里已经足以理解网页上“预测 → 误差 → 调整参数”的循环。

## 5. 导数是什么（想深究时再读）

导数在这里描述“**权重稍微变动，误差大约怎么变**”，不是准确率，也不是权重本身。对上面的单权重例子，误差函数是 `L(w)=(w×3-4)²`。在 `w=2` 附近，`L(2.01)=4.1209`，`L(1.99)=3.8809`；两者相差 `0.24`，权重相差 `0.02`，所以局部变化率约 `0.24÷0.02=12`。这只是用相邻值估计斜率。

这个玩具函数的精确导数是 `dL/dw=2×(w×x-目标)×x`；代入 `w=2、x=3、目标=4`，得到 `2×(6-4)×3=12`。若学习率为 `0.01`，沿相反方向走一步：`w新=2-0.01×12=1.88`，对应上一节的误差 `2.6896`。**不要由此推断任何步长、任何复杂网络更新后 loss 都必然下降**：那是这一个玩具例子的一步计算。PyTorch 的 `backward()` 为真实网络自动计算很多权重的梯度，优化器再更新它们；网页基础课程只需知道这件事的目的，不必手推公式。
